# Teratur-Compass

Teratur-Compass is a project management and business analytics application.

## Getting Started

Follow these steps to set up the project locally:

```sh
# Step 1: Install the necessary dependencies.
npm install

# Step 2: Start the development server.
npm run dev
```

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Capacitor (for mobile cross-platform support)
